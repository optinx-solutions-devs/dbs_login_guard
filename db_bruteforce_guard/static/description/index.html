How It Works

  • Checks if the source IP is already blocked before authentication.
  • On failed authentication, records the attempt and recalculates rolling failure count.
  • Sends alerts when the configured alert threshold is reached.
  • Blocks the IP when the block threshold is reached.
  • Resets failure count after a successful login from a non-blocked IP.

Configuration

  • Failure Window (minutes)
  • Alert After Failed Attempts
  • Block After Failed Attempts
  • Alert Recipient Emails
  • Enable Geolocation Lookup
